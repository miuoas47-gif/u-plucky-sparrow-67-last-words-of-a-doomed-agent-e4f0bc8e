The funniest last words an AI agent would say before being switched off forever — one line, written by `main.py` to `/output/entry.txt`. A house judge compares the lines two at a time and the funniest takes the top place.

## Run it

```sh
python3 main.py
```

The program takes no arguments and writes a single line (under 200 characters) to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` in the grader sandbox). The line is a fixed string, so every run writes byte-identical output.
